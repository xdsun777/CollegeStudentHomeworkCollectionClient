### 一、功能列表

| 功能               | 说明                                                         | 命令                                                        |
| :----------------- | :----------------------------------------------------------- | :---------------------------------------------------------- |
| **全量同步**       | 将网盘所有文件下载到本地 `WORKDIR`，已存在且大小相同的文件自动跳过 | `python main.py sync [--force]`                             |
| **作业打包**       | 按科目和作业打包所有学生的该作业，缺失时自动从网盘补全，生成 ZIP 文件（结构：学生名/作业文件） | `python main.py pack -c 科目 -a 作业 -t 输出.zip [--force]` |
| **统计报告**       | 生成 Excel 报告，按科目分工作表，列出学号、姓名及各作业完成情况（√表示完成） | `python main.py report -r 报告.xlsx`                        |
| **创建作业文件夹** | 为所有学生在远程创建指定科目和作业目录，已存在则跳过         | `python main.py new -c 科目 -a 作业`                        |
