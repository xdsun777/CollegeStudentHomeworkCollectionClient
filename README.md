# 基于dufs后端的作业收集客户端



## 一、环境准备

### 1. 安装依赖

bash

```
pip install python-dotenv requests openpyxl
```



### 2. 配置 `.env` 文件

在脚本所在目录创建 `.env`，内容如下：

ini

```
WORKDIR=      # 本地工作目录
BASE_URL=     # 网盘根地址
USER=         # 管理员账号
PASSWD=       # 密码
```

## 二、命令行用法

| 功能                           | 命令                                                         | 说明                                                         |
| :----------------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **全量同步**                   | `python main.py sync`                                        | 下载网盘所有内容到本地 `WORKDIR`，已存在且大小相同的文件跳过 |
| **全量同步（强制）**           | `python main.py sync --force`                                | 强制覆盖所有本地文件                                         |
| **同步学科所有作业**           | `python main.py sync -c "数学"`                              | 为每个学生同步“数学”学科下的全部作业                         |
| **同步学科指定作业**           | `python main.py sync -c "数学" -a "作业1"`                   | 为每个学生同步“数学/作业1”                                   |
| **打包作业**                   | `python main.py pack -c "数学" -a "作业1" -t "作业包.zip"`   | 将每个学生的“数学/作业1”打包为一个 ZIP 文件                  |
| **打包作业（强制）**           | `python main.py pack -c "数学" -a "作业1" -t "作业包.zip" --force` | 强制重新下载后打包                                           |
| **生成报告**                   | `python main.py report -r "完成情况.xlsx"`                   | 生成 Excel 报告，按科目分工作表，√ 表示完成                  |
| **创建作业文件夹**             | `python main.py new -c "数学" -a "作业1"`                    | 为每个学生在远程创建“数学/作业1”目录                         |
| **删除作业文件夹**             | `python main.py delete -c "数学" -a "作业1"`                 | 删除每个学生远程的“数学/作业1”目录（需确认）                 |
| **删除作业文件夹（跳过确认）** | `python main.py delete -c "数学" -a "作业1" --yes`           | 直接删除，不询问                                             |

>   注：若不使用子命令，直接运行 `python main.py` 等同于 `sync`（全量同步）。
>   若使用旧版参数（如 `-c` 不带子命令），也会自动识别为同步学科/作业。

## 三、图形界面用法

启动 GUI：

bash

```
python gui.py
```



### 1. 配置页

-   填写本地工作目录、网盘地址、用户名、密码
-   点击“保存配置”保存到 `.env`
-   点击“测试连接”验证网盘认证是否成功

### 2. 功能页

选择功能后，下方会显示对应的参数输入区域：

-   **全量同步**
    无参数，直接点击“执行”即开始下载全部文件。
    可选“强制覆盖”复选框。
-   **同步学科/作业**
    -   选择“学科”（必选，从下拉框选择）
    -   可选“作业”（留空则同步该学科下所有作业）
    -   可选“强制覆盖”
    -   点击“执行”开始为每个学生同步指定内容。
-   **打包作业**
    -   选择“学科”和“作业”（从下拉框选择）
    -   指定输出 ZIP 文件路径
    -   可选“强制覆盖”
    -   点击“执行”生成 ZIP。
-   **生成报告**
    -   指定输出 Excel 文件路径
    -   点击“执行”生成报告。
-   **创建作业文件夹**
    -   输入“学科”和“作业”名称（可手动输入，也可点击“从网盘选择”参考已有目录）
    -   点击“执行”为每个学生在远程创建目录。
-   **删除作业文件夹**
    -   选择“学科”和“作业”（从下拉框选择）
    -   点击“执行”，程序会列出待删除的目录并要求确认（日志区域会出现确认提示，输入 `y` 确认）。

所有执行过程的输出都会实时显示在“日志”页，包括下载进度、错误信息等。

## 四、注意事项

-   **学生文件夹识别**：脚本只处理名称符合 `数字-姓名`（如 `2025200331-陈红林`）的文件夹，其他目录（如 `other`）会被自动忽略。
-   **远程路径**：使用 `/` 作为分隔符，大小写敏感，请确保学科/作业名称与网盘完全一致。
-   **强制覆盖**：`--force` 或“强制覆盖”选项会使脚本忽略本地已有文件，重新下载/覆盖。
-   **网络异常**：单个文件下载失败不影响其他文件，错误信息会打印在日志中。
-   **删除确认**：删除作业文件夹时，默认会先列出所有待删除路径并询问确认，可使用 `--yes` 跳过。

## 五、常见问题

1.  **为什么“同步学科/作业”时有些学生跳过了？**
    因为本地已存在且非空，且未使用强制覆盖。如需重新下载，请勾选“强制覆盖”或使用 `--force`。
2.  **报告中的“完成”如何判断？**
    只要该学生的作业文件夹下存在任何文件（非空），即标记为“√”。
3.  **创建作业文件夹时，如果科目目录不存在会怎样？**
    脚本会自动创建科目目录，再创建作业目录。
4.  **打包作业时，如果某学生没有该作业怎么办？**
    脚本会跳过该学生，并提示“无此作业”，不影响其他学生。
5.  **GUI 中下拉框内容为空？**
    请先检查配置页的网盘地址、用户名、密码是否正确，并点击“测试连接”验证。连接成功后，点击“刷新学科”即可加载。
